你接下来按这几步操作：

  1. 到 GitHub 新建仓库，例如 wc26-match-data。
  2. 只上传 D:\Dev\WC26\Server 里面的内容到仓库根目录：public/data/match.csv、
     vercel.json、README.md。

  3. 到 Vercel 点 New Project，选择这个 GitHub 仓库。Vercel 官方文档说明 Git 仓
     库导入后，每次 push 会自动部署；项目配置也可用 vercel.json 控制 headers。参
     考：
     https://vercel.com/docs/deployments/git
     https://vercel.com/docs/project-configuration/vercel-json

  4. Vercel 配置建议：
      - Framework Preset：Other
      - Build Command：留空
      - Output Directory：public
      - Root Directory：如果仓库只放了 Server 内容就留空；如果你上传了整个
        WC26，就填 Server

  5. 部署完成后，打开这个地址确认能看到 CSV：
     https://你的项目名.vercel.app/data/match.csv

  6. 把这个 URL 填到 App/app/build.gradle.kts:20，替换现在的：
     https://YOUR_VERCEL_PROJECT.vercel.app/data/match.csv

  7. 重新构建 APK。以后只要改 GitHub 里的 public/data/match.csv 并提交，Vercel
     自动部署，App 下拉刷新就会取最新结果。
